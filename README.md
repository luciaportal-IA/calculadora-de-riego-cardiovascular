CALCULADORA DE RIESGO CARDIOVASCULAR

Este es un software desarrollado en Python que permite evaluar el riesgo cardiovascular utilizando el modelo de Framingham. 
El objetivo es brindar una herramienta precisa para el cuidado preventivo de la salud.

# Funcionalidades
* Evaluación automática basada en edad, presión arterial, niveles de colesterol y otros factores clave.
* Implementación precisa del modelo de Framingham para el cálculo de riesgo cardiovascular a 10 años.
* Diseño intuitivo y amigable desarrollado para facilitar la interacción del usuario.
* link de ayuda incorporada para orientar al usuario en caso que no sepa algun dato preciso.
* Capacidad de generar una "receta médica" o reporte de resultados basado en los datos ingresados.

# Tecnologías usadas
* Lenguaje: Python
